# Brief — 청첩장모임 스케줄러

## 보여준 레퍼런스

- oh-my-design.kr/builder에서 사용자가 직접 "콘텐츠/미디어 × 소셜 피드형 미니멀" 무드로 후보를 브라우징 → **카카오(Kakao) DESIGN.md** export 확정.
- (참고로 함께 다운로드된 네이버페이 DESIGN.md는 이번 프로젝트에서는 사용하지 않음 — 동일 폴더에 다른 세션 산출물이 있어 혼동 방지차 새 폴더로 분리)

## 역추출한 암묵적 판단기준

- 카카오 DESIGN.md의 "마케팅 옐로우(#fae100)와 로그인 옐로우(#fee500)를 혼용하지 말라"는 규정 → 로그인 컴포넌트가 없는 이 앱에는 문자 그대로 적용 불가. 배후 원칙만 추출: **"액센트 컬러 하나를 정하면 그 컬러는 단 하나의 의미(이 앱에서는 '확정' 액션)에만 쓰고 다른 용도로 전용하지 않는다."**
- 이 원칙에서 파생: 신랑/신부 구분에 색을 새로 만들지 않고 텍스트+아웃라인 배지만 사용(옐로우를 신랑/신부 구분에 쓰면 "확정" 의미가 희석됨).
- 카카오 코퍼레이트 사이트의 컴포넌트(네비 필, 서치, 마일스톤 필터, 다크 마케팅 태그, 푸터 필)는 전부 flat(그림자 없음) + pill 라운드 + 4/6/8/16/20 컴팩트 스페이싱 리듬 → 이 프로젝트 전체 스페이싱/라운드 토큰으로 채택.
- DESIGN.md가 명시적으로 "카카오톡 채팅버블·탭바·뱃지 등은 검증되지 않았으니 지어내지 말라"고 경고 → 이 앱의 소셜 피드/모임 카드 UI 컴포넌트는 카카오 레퍼런스에서 가져올 수 없어 이번 프로젝트에서 직접 설계함(색/타이포/스페이싱 토큰만 이식, 컴포넌트 패턴은 자체 설계).

## 명시적 가정 로그

- PRD가 "화면 구성 미명시 그린필드"라 화면 수·IA는 하네스가 설계 — 브레인스토밍 B단계에서 IA 3안을 사용자에게 제시해 확정.
- KakaoBig/KakaoSmall 폰트는 재배포 권한이 확인되지 않아 **Pretendard로 영구 대체**(추후 data-todo 아님 — 확정 대체).
- 확정 공유 카드의 "장소" 필드는 PRD에 정보가 없어 `data-todo="장소 미확정 — 준비 중"`으로 남김.
- 응답자(초대받은 지인)도 앱 계정을 갖고 여러 커플의 요청을 한 받은함에서 본다고 가정(PRD 유저스토리 2번 "여러 커플로부터 동시에 요청을 받아 한번에 파악"을 근거로 함).

## 추출된 디자인 토큰 값

- Background(Canvas): `#ffffff`
- Foreground(기본 텍스트): `#333333`
- Muted: `#888888`
- Surface(필/배지 배경): `#eeeeee`
- Border: `#dbdbdb`
- Dark(강조 배경): `#111111`
- Ink(최상위 텍스트/버튼): `#000000`
- Accent(Yellow, 확정 액션 전용): `#fae100` / tint `#fffbe0`
- Spacing 그리드: 4 / 6 / 8 / 16 / 20 (px)
- Radius: pill(999px, 필/버튼), 20px(카드), 8px(입력/일반 버튼)
- 타이포: Pretendard (KakaoBig/KakaoSmall 대체, 재배포 권한 미확인으로 인한 영구 치환)
