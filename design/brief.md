## 4. 역추출한 판단기준 (6건 · 전건 provisional)
### RULE-01
- statement: 사람을 모임에 넣거나 고르는 화면에서는 이름 옆에 관계 그룹을 함께 보여준다
- source_quote: "회사 팀장님 같은 어른을 단체 모임에 실수로 같이 끼워 넣어요" (A-05) / 질문 원문 "여기서 뭔가 빠뜨리거나 잘못되면 뭐가 제일 곤란해요?" (Q-02 = 뼈대 Q5)
- translation: 번역표 "실수할 것 같아요" → 확인 단계·되돌리기. 여기서는 실수의 원인 정보(소속·중복)를 결정 시점 화면에 상시 노출로 확장 — 표에 없는 표현이라 `provisional`
- source_refs: [A-05, Q-05]
- axis: domain
- exception: 확정 공유 화면처럼 재선택이 불가능한 화면은 이름만 표기 허용
- verdict_method: A
- borrow_scope: element
- confidence: provisional
- audit: over_generalized — 관계 구분은 뿌리 있으나 '이미 잡힌 모임' 표시·전 화면 강제는 근거 밖

- source_quote: "마감이 지나면 그 모임이 맨 위 별도 칸으로 옮겨가서 '지금 정하세요'라고 크게 보여요" (A-11, 답 B) / 선택 원문 "B" [PRD-PUSHBACK] (A-11, PRD 반박 최빈 상태 미처리)
