# A검사 7 (아이콘 덮임) — 검출력 시험

> 2026-09-06 · 표적 검증. 리포트는 **메인이 직접 작성**했다 —
> 검사를 맡은 서브가 "세부는 이 파일 참조"라고 보고했으나 파일을 만들지 않아,
> 메인이 read-only 스크립트로 재현했다(D-13).

## 판정 규칙

아이콘 안에 `visible` 한 VECTOR/BOOLEAN_OPERATION 이 ≥1 이고,
그 벡터를 **덮는 불투명 노드가 없어야** PASS.

"덮는다" 3조건:
1. 노드 `opacity` ≥ 0.9 **그리고** fill `opacity` ≥ 0.9
2. 노드의 절대 경계가 벡터의 절대 경계를 포함
3. 같은 부모 안에서 벡터보다 뒤 인덱스(= 위에 그려짐)

검사 대상은 **화면 프레임 안의 INSTANCE**. 마스터만 보면 안 된다(D-10: 마스터 정상, 인스턴스만 덮임).

## (1) 합성 케이스 — 검출기가 작동하는가

`__TEST__` 페이지에 일부러 두 케이스를 만들어 시험했다(시험 후 페이지 삭제).

| 케이스 | 구성 | 기대 | 실제 |
|---|---|---|---|
| `TEST Screen / good` | 24×24 프레임에 18×18 벡터만, 컨테이너 fill 없음 | PASS | **PASS** |
| `TEST Screen / bad` | 같은 구성 + 벡터와 **같은 색** 24×24 불투명 사각형이 벡터 뒤 인덱스에 | FAIL | **FAIL** |

`bad` 에서 `duo-fg` RECTANGLE(24×24, opacity 1.0, fill opacity 1.0, 벡터보다 뒤)이 벡터(18×18)를 완전히 덮는 것을 정확히 지목했다.

**DETECTOR: 작동함.** 이전 런에서 사용자가 세 번 지적할 때까지 못 잡았던 결함을 기계가 잡는다.

## (2) 실제 화면 — Screens 페이지 24프레임

메인이 직접 실행한 스크립트 결과:

```
framesScanned: 24
iconInstancesWithVectors: 9      (탭바 인스턴스 9개)
visibleVectors: 90               (탭바당 10개 × 9)
coveredCount: 0
findings: []
```

**RESULT: PASS** — 덮개 0건.

이전 런의 `duo-fg` 케이스는 이미 수정되어 재현되지 않았으므로, 합성 케이스로 검출력을 따로 확인했다. 결함이 없는 상태에서 PASS 가 나온 것과 검출기가 작동하는 것은 다른 사실이며, 둘 다 확인해야 검사가 의미를 갖는다.
