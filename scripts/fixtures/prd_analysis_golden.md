# PRD 분석 — 반려동물 복약 알림

## 1. 화면 흐름 후보 1개
도출 7단계: 동사 8개(등록·일정·먹임·확인·공유·알림·조망·되돌리기) → 객체 3개(반려동물·약·복약 기록) → 상태 4개 전이 → 역할 2개(보호자·돌봄 대리인) → 주 화면 7장.

| 화면 | 진입 경로 | 이 화면의 1등 정보 | 기능 매핑 | 1차 목적 |
|---|---|---|---|---|
| 홈(오늘 복약 보드) | 앱 실행 직후 | 오늘 남은 복약 건수 | F5 | 빠른 처리형 |
| 첫 등록(반려동물·약) | 첫 실행 | 첫 반려동물 등록 버튼 | §2-1 | 입력형 |
| 약 등록·일정 | 홈 + 버튼 | 다음 복용 시각 | F2 | 입력형 |
| 돌봄 공유 링크 | 약 등록 완료 직후 | 공유 링크 | F4 | 빠른 처리형 |
| 대리인 복약 확인(외부) | 공유 링크 | 지금 먹여야 할 약 | F3 | 빠른 처리형 |
| 알림 목록 | 푸시 탭 | 놓친 복약 건수 | §2-3 | 현황 파악형 |
| 설정·탈퇴 | 홈 상단 메뉴 | 탈퇴 버튼 | §2-4 | 입력형 |

상태 순위표 — 기준 "지금 할 일이 있는가"
| 순위 | 상태 | 지금 할 일 | 근거 |
|---|---|---|---|
| 1 | 이중 투약 경고 | 있음 — 한 번 더 먹이면 되돌릴 수 없다 | F5, `[HYPOTHESIS]` 인터뷰 Q5로 검증 |
| 2 | 복약 놓침 | 있음 — 지금 먹일지 건너뛸지 결정 | §3 "시간이 지난 약" |
| 3 | 예정(시각 전) | 없음 — 기다리는 중 | F5 |
| 4 | 먹임 | 없음 — 약화 | F5 |

## 2. 시나리오 내러티브 2개
S-1: 아침 약을 먹였는지 헷갈리는 상황에서 홈을 열어 '이미 먹임' 표시를 확인한다.
S-2: 부모님이 공유 링크를 열어 지금 먹일 약 하나를 확인하고 '먹였어요'를 누른다.
