# PRD — 수제 가구 커머스 "우드바이"

## 1. 개요
1인 목공방이 직접 만든 원목 가구를 파는 상품 상세 페이지.
객단가 40~180만원. 사용자는 최소 3회 이상 재방문한 뒤 구매한다.

## 2. 사용자
- **30~40대 신혼·이사 가구 구매자**: 가격이 높아 즉시 구매하지 않는다. 저장하고 다시 본다.
- 대부분 출퇴근 지하철에서 세로 모바일로 본다. 한 손 조작.
- 사진 화질과 나뭇결 표현이 구매 결정의 절반이다.

## 3. 핵심 화면 구성
1. 상품 이미지 갤러리 — 최소 8장, 확대 가능
2. 가격·옵션 선택 — 원목 종류 3종 × 사이즈 4종 = 12조합, 조합마다 가격과 납기가 다름
3. 제작 과정 스토리 — 긴 스크롤 콘텐츠
4. 배송·설치 안내 — 사다리차 필요 여부 등 조건이 복잡함
5. 하단 고정 구매 CTA

## 4. 상태
- 재고 없음 / 주문제작(납기 6주) / 즉시배송 3종
- 옵션 미선택 상태에서 CTA를 누르면 옵션 선택으로 유도되어야 한다
- 찜하기 상태(로그인 필요)

## 5. 제약
- 사진이 주인공이다. UI 색이 사진과 경쟁하면 안 된다.
- 납기 6주를 숨기면 클레임이 발생한다. 구매 전에 반드시 보여야 한다.
- 하단 고정 CTA가 스토리 콘텐츠를 가리는 문제가 기존 페이지에 있었다.

## 6. 성공 지표
- 옵션 선택 완료율
- 재방문 후 구매 전환율
