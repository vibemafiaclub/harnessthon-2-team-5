# PRD — 물류 운영 대시보드 "Trackboard"

## 1. 개요
중견 3PL 물류사의 내부 운영팀이 하루 종일 띄워 두고 쓰는 배송 관제 화면.
사용자는 이 화면을 8시간 연속으로 본다. 하루 평균 조회 건수 2,000건.

## 2. 사용자
- **관제 담당자(주)**: 30~50대, 듀얼 모니터, 마우스 위주. 화면을 "읽지" 않고 "훑는다".
- **팀장(부)**: 하루 2~3회 요약만 확인.
- 사용 환경은 사무실 형광등 아래 고정. 야간 근무조 있음.

## 3. 핵심 화면
1. 배송 현황 테이블 — 한 화면에 최소 25행. 컬럼 12개(운송장, 출발지, 도착지, 상태, ETA, 지연, 담당, 차량, 중량, 특이사항, 갱신시각, 액션)
2. 이상 건 패널 — 지연/파손/미배차 3종을 우선순위로 정렬
3. 차량 배차 보드 — 드래그 앤 드롭

## 4. 상태
- 배송 상태 7종: 접수 / 집화 / 간선 / 배송중 / 배송완료 / 지연 / 실패
- 이상 건은 위 상태와 **직교**한다. 배송중이면서 지연일 수 있다.
- 실시간 갱신(15초). 갱신 중에도 사용자의 스크롤 위치와 선택이 유지되어야 한다.

## 5. 제약
- 색약 사용자가 팀에 있다. 상태를 색만으로 구분할 수 없다.
- 한 행의 높이가 40px를 넘으면 한 화면에 25행이 안 들어간다.
- 기존 사내 시스템이 회색 계열이라 급격한 브랜딩 변경은 거부감이 있다.

## 6. 성공 지표
- 이상 건 인지까지 걸리는 시간 3초 이내
- 8시간 사용 후 눈 피로 호소 감소
