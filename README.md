# oss-design-harness

PRD를 비전문가와의 인터뷰로 보강하고, 실제 모바일 레퍼런스와 HTML 시안을 거쳐 편집 가능한 Figma UI·UX를 만드는 디자인 하네스입니다.

현재 버전은 **v0.6.0-draft**입니다. 제품 과업 보존과 납품 완결성을 보강한 실험본이며, 실제 품질 개선·다른 PRD에서의 재현·전문 외주 동등성은 아직 검증되지 않았습니다.

## 판단 원칙

- 제품의 요구·행동·상태를 레퍼런스 외형보다 우선합니다.
- 비전문가에게 사업 상황과 실제 화면 반응을 묻고, 전문 디자인 판단은 에이전트가 맡습니다.
- 요구사항을 역할별 과업·화면·상태·검수 증거까지 연결합니다.
- 실제 화면의 시각 품질과 Figma 속성·편집 가능성을 각각 검사합니다.
- 제작 완료, 내부 검수, 독립 검수, 고객 수용을 구분합니다.

## 진행 과정

| 단계 | 결과 |
|---|---|
| 0. 요구사항 정렬 | 보강 PRD, 범위와 역할별 과업·행동·상태 |
| B. 레퍼런스·시안 | 실제 모바일 자료, 디자인 시스템 적용, HTML 기준안과 선택 |
| Q. HTML 품질 판정 | 핵심 과업 연결, 모바일 제약, 시각 품질과 실제 관찰 |
| A/C. Figma 제작·검증 | 편집 가능한 화면·컴포넌트·스타일과 실제 렌더 검수 |
| D. 납품·인계 | 요구별 최종 노드, 프로토타입, 개발 전달 정보와 남은 한계 |

모바일 웹/iOS/Android 중 프로젝트에 맞는 대상을 정합니다. 데스크톱·태블릿 제품 화면과 실제 백엔드 개발은 이 하네스의 범위가 아닙니다. HTML 시안은 로컬에서 검증하고 최종 산출물은 Figma로 제작합니다.

## 새 실행 준비

새 대화에서 아래 요청을 사용합니다. 실행 준비를 담당하는 에이전트는 기존 실행과 겹치지 않는 폴더를 만들고, 하네스와 필요한 참조·템플릿·PRD·실행 지침을 고정합니다. `.claude/skills`의 자동 인식을 전제하지 말고 고정한 `harness.md`를 명시적으로 읽도록 합니다.

```text
이 레포의 디자인 하네스로 내 PRD를 디자인하고 싶어.

먼저 기존 실행과 겹치지 않는 새 실행 폴더를 준비하고,
현재 하네스와 필요한 참조·템플릿·실행 지침·PRD 원문을
스냅샷으로 고정해줘. 입력 파일의 SHA256도 기록해줘.

별도의 새 대화에서 사용할 실행 시작 프롬프트를 만들어줘.
지금은 준비까지만 하고 디자인 실행은 시작하지 마.
이전 실행의 사용자 취향·답변·시안·평가·개선 기록은
이번 실행의 입력으로 가져오지 마.

PRD: [문서 본문 또는 링크]
최종 Figma 파일: [파일 링크]
해당 파일의 새 실행 전용 페이지를 사용하고 기존 페이지는 수정하지 마.
```

준비한 시작 프롬프트를 별도의 새 대화에서 실행합니다. 실행 지침에는 다음 경계를 포함합니다.

- 고정 입력의 해시를 확인하고 해당 실행의 입력·결과만 읽습니다. 실행 중 하네스 버전을 바꾸지 않습니다.
- 원본의 `references/`와 레포의 `templates/`를 실행 폴더 아래에 복사해 상대 경로를 유지합니다. 하네스 본체는 `harness.md`로 복사합니다.
- 필요한 질문은 이번 사용자에게 직접 묻고, 답변·선호·검증 결과를 지어내지 않습니다.
- HTML 선택과 핵심 흐름 품질 판정 후 지정 Figma 파일의 새 페이지에서 제작합니다. 기존 페이지의 내용은 조회하거나 수정하지 않습니다.
- 실행 폴더와 Figma 페이지 ID를 기록하고 다른 실행의 브라우저 탭·서버·프로세스를 재사용하거나 종료하지 않습니다.
- 플랫폼에 필요한 브라우저·Figma 도구와 스킬을 사용하고 추가 지침·가정·미검증 사항을 기록합니다. 도구 접근이 없으면 성공을 주장하지 않습니다.

Figma 편집 도구와 실제 브라우저 검증 환경이 필요합니다. 로그인·접근 권한은 실행 환경에서 확인합니다. 최종 Figma 링크가 없으면 준비 단계에서 사용자에게 확인합니다.

## 파일 구조

- [.claude/skills/oss-design-harness/SKILL.md](.claude/skills/oss-design-harness/SKILL.md): 하네스 본체
- [.claude/skills/oss-design-harness/references/](.claude/skills/oss-design-harness/references/): PRD 보강, 출처 정책, 레퍼런스 적용, 품질과 납품 기준
- [templates/](templates/): `brief.md`, `prd-enriched.md`, `decisions.md`, `delivery.md`
- [docs/concept.md](docs/concept.md): 초기 설계 배경. 현재 실행 규칙은 하네스 본체를 따릅니다.

실행 결과는 별도의 실행 폴더에 작성합니다. `execution.md`에는 실제 질문·답변, 도구·시간·재작업·개입, 검증 결과와 한계를 기록합니다. 다른 PRD에서도 효과가 재현되는지 확인한 뒤 공통 규칙으로 평가합니다.
